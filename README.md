# Road Accident Analysis Dashboard | Excel

An interactive Excel dashboard developed to analyze road accident data and identify accident trends and patterns.

## Project Overview

This project analyzes road accident data using Excel to understand accident patterns based on road type, road surface, location, and other factors.

## Key Features

- Data cleaning and analysis
- Pivot Tables and Pivot Charts
- Accident trend analysis
- Road type and road surface analysis
- Location-based analysis
- Interactive dashboard

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Visualization

## Dataset

The original dataset contains a large number of accident records.  
For GitHub sharing, **only 1,000 sample rows** are included in this repository to keep the file size manageable.

The dashboard and analysis demonstrate the approach used to analyze the complete dataset.

## Project Structure

- `Road_Accident_Analysis_Dashboard_GitHub.xlsx` – Excel dashboard and analysis
- `README.md` – Project documentation

## Dashboard

The dashboard provides visual insights into road accident trends, road conditions, and accident patterns.
